Show, hide, add, edit and remove the projects on the public page.

Sign in with a GitHub token

Changes are saved as commits to data/projects.json in mendus59/mendus59.github.io, which redeploys the site. The token stays in this browser and is only sent to api.github.com.

  1. Open GitHub → new fine-grained token.
  2. Repository access: Only select repositories → mendus59.github.io.
  3. Permissions: Contents → Read and write. Nothing else.
  4. Generate it and paste it below.
