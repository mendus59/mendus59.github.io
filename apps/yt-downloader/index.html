YT Downloader

A simple Windows window on top of yt-dlp: paste a link, pick a quality, download.

Download for Windows (.exe) Open the web app Source on GitHub

Free, one file of about 60 MB, for Windows 10 and 11. No installer, no account. Downloads run on your own PC.

What it does

  • Paste and go: one or more video, playlist or channel URLs at once.
  • Video or audio: set a maximum quality and a minimum (videos that don't reach it are skipped), or download audio only as mp3, m4a, opus, wav or flac.
  • Whole playlists and channels, optional English subtitles, and the video ID in file names if you want it.
  • Stays in control: live progress, Skip current video, Cancel all, and it keeps going when one video fails.
  • Everything bundled: Python, yt-dlp and deno (the JavaScript runtime YouTube now requires). A Get ffmpeg button adds ffmpeg once, for 1080p+ merging and audio conversion.
  • Web app: the web page builds your settings and its Open in YT Downloader button launches the app with them filled in, through a ytdlp-gui:// link.

Install on Windows

  1. Download YT-Downloader.exe and put it anywhere, such as your Desktop.
  2. Double-click it. The app isn't code-signed, so Windows SmartScreen may warn you: click More info, then Run anyway.
  3. For 1080p and higher, or mp3 conversion, click Get ffmpeg once.
  4. Paste a URL, choose your options and click download. To start from the browser, use the web app's Open in YT Downloader button; Windows hands the link to the app (no admin rights needed).

New versions are published as GitHub Releases; the download link above always gets the newest. Release notes

Why the web app doesn't download videos itself

GitHub Pages only serves static files, and browsers block pages from fetching video from other sites. A public download server would cost money, get blocked by YouTube and invite abuse, so the web app hands your settings to the desktop app and downloads happen on your computer.

Only download content you have the right to. YouTube's Terms of Service restrict downloading outside its own features. Not affiliated with YouTube or the yt-dlp project.
